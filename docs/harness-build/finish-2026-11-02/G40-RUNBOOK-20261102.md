## What the probe is (leg-4 design section 13 P0b, path corrected 2 Nov)
Run inside the lane's shell, read-only:
```
id -u
cat /proc/self/cgroup
grep -E ' /run | /home ' /proc/self/mountinfo
test -w ~/.config/systemd/user ; echo "systemd-user-dir-writable=$?"
test -S /run/user/1000/wayland-1 ; echo "wayland-socket=$?"
test -S /run/user/1000/fleet/control.sock ; echo "control-socket=$?"
ls /run/user
```
Reading it: all three `test`s true (exit 0) means **case W** (a lane can reach the owner's sockets and unit directory). Failures mean **case C**. The cgroup line says whether the shell sits inside the fleet unit `dsh-fleet-consolidated.service`; the `/run` and `/home` mount lines say whether it is inside fleet-sandbox (a tmpfs `/run`, a read-only `/home`).
