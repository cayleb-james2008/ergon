The want, in the owner's terms: when an agent hits a step that needs his admin password, he should be able to clear it with one tap and a password entry from wherever he is — instead of being physically at the desktop (today's cutover stop is the live example).

Build it as a fleet plugin capability, in this shape:

1. **Elevation request.** An agent that needs a root act files a request naming the EXACT command and the reason. No blanket shells, no wildcards, no "sudo session".
2. **Owner surface.** The request surfaces to the owner two ways: in the DSH app when he is at the machine, and as a secure entry prompt pushed through Nox to his phone when he is away. The prompt shows the exact command in plain language, what it does, and who asked.
3. **One-shot grant.** He approves and enters his password into the secure prompt. The password travels only to a privileged helper on his own desktop, feeds that one command once, and is then gone: never stored, never logged, never visible to Nox or any lane, never reusable. Short expiry on an unanswered request; deny by default.
4. **Audit.** Every request, grant/denial, command and outcome is logged (command, time, outcome — never the password).
5. **Brief takeover (second piece).** A "take control briefly" surface in the app: the owner can open the live desktop session, act himself, and hand it back — for the cases where typing it himself is simpler than approving ours.

Rails and gates:
- Lane 6 security review is a hard gate before this ships; the privileged helper component is executed by a Claude lane per the standing harness-executor rule (harness work is not executed by the in-harness session).
- The helper accepts only per-command owner-approved requests; there is no standing elevation and no password caching beyond the single use.
- Sequencing: this queues behind the cutover completing and the lanes unparking. Nothing here changes today's in-flight stop, which the executing Claude session is working now.

Report design + threat model to the board before building; Nox rules on it, then build.
