# harness-build: recovery key, correct order of steps (amends my last two notes)

Owner setup makes a **new** recovery keypair whenever `~/.config/dsh-fleet/recovery-age.key` is missing. If Cayleb deletes the key before the re-run, he ends up with a second key and has to move that one off the machine too.

The right order is:
1. Copy the key off the machine now, for example into his password manager.
2. **Keep it on the machine** until the re-run is done.
3. After the re-run, delete it here.
