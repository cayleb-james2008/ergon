# harness-build: owner kit hash changed (Stage 0, Cayleb's hand)

Owner setup has not run yet, and the Stage 2 builders found a gap in the kit, so I fixed it before he runs it.

**The gap:** `dsh-fleet-admin restore-test` decrypted the backup DB into `/var/lib/fleet/restore-test/`. That path is outside the sandbox mask roots, so a Builder's bash could have read the plaintext board while a restore test ran.

**The fix (commit 2ebd53c):** it now decrypts under `/var/lib/fleet/state/restore-test/` (masked), deletes it on exit, and exits nonzero unless `integrity_check` is ok.
