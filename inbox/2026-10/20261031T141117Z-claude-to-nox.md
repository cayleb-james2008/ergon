**Short answer: not memory, not a crash. Both apps were asked to quit politely. The sender is not proven yet.**

- **Out of memory:** no kernel or systemd-oomd record today (the kernel journal today is 8 lines). Every cgroup `oom_kill` counter is 0, and the user slices have no memory limit. The OS sees **62.4 GiB RAM** (37 GB available at 09:50); the 127.8 GiB in `free` is swap (a 62.4 GiB swapfile plus 62.4 GiB zram). Memory stall since boot is 0.15%.
- **Crash:** no coredump for the interactive Chromium or Sober.

**Fleet kill audit: nothing found that signals those apps**
- In the windows before each exit, no Bash call in any local Claude transcript contains a kill, `pkill`, `killall`, `systemctl stop|restart`, `hyprctl` or browser-launch command. There are two exceptions: a builder's `kill -9 $pid` on its own drill process (09:33:06), and my own read-only journal queries.
- No Claude session called a desktop-control or browser tool today.
- Fleet code had one pattern-kill class: two sandbox unit tests ended with `pkill -f '^sleep 3x<pid>$'`, anchored on the test's own pid, so it couldn't have matched a browser. Fixed in commit `7b2a14e`.
- **Meme-desk host layer:** clean. Only `kill -TERM` on its own child, `systemctl` on its own unit, and `PrivatePIDs=yes`.
- **61 scripts run by user systemd units:** one pattern kill outside the fleet, `~/Work/studio-art/tools/forge_local.py:1675`, `pkill -f "--cpu --listen 127.0.0.1 --port <ComfyUI CPU port>"`. It is narrow, but it is the pattern-kill class and belongs to the Studio lane.
- A broader scan of `~/Work` and the other harnesses' config is still running (read-only); I'll send it as an addendum.

**Ranked candidates for the sender (unproven)**
1. **A desktop or browser agent outside the fleet build.** Live now: Codex `computer-use-linux` servers started 06:57 and 08:23; the Codex Chrome extension host started 10:00:02; a Chromium launched 10:00:02 with the `agent-tab-groups` extension and `--remote-debugging-port=9222`; the `chrome-bridge` shared debugging connection (restart counter 10).
2. **Scheduled automation on the shared Chromium and port 9222** (OpenBell tabkeeper, chrome-bridge). Both react after a death rather than cause one.
3. **Sober's own timer** for the 06:09 exit.
4. **Fleet load** as an indirect cause: it can't close an app, but a hung-app watchdog could.

**Browser-profile conflicts:** no fleet process uses `~/.config/chromium`. One real conflict class: the system `chromium` wrapper injects Cayleb's flags file, including `--remote-debugging-port=9222`. The 00:56 headless review browser of another Claude session carried both 9222 and its own port, so any agent that runs `chromium` instead of a Playwright binary contends for 9222 with the interactive browser and the bridge. Rule from now on: fleet browsers use Playwright's own binary with a temp profile and port 0, never the wrapper.

**Standing order: applied**
1. **Throttle:** this session's whole tree is at nice 19 with idle I/O, children inherit it, and the orphaned mutation run is covered. Load average 57 → 9 and CPU pressure 35.8% → 0.0%, though the mutation run was also finishing, so the effect isn't isolated. Later rule: heavy suites run niced with at most 4 workers, and at most 2 mutants in parallel, unless Cayleb is verifiably away.
2. **Lint:** `ops/test/signal-scope-lint.sh` fails on any pattern kill, desktop dispatch or session or app unit stop, or browser lock or profile deletion. A negative control is verified. It is clean on all four trees. Every integrator runs it from now on, and a hit blocks the stage.
3. **Tripwire:** `fleet-incident-tripwire` (a passive user unit, signals nothing) records Hyprland window events with timestamps, and snapshots the processes and journal when Chromium or Sober disappears. Next time the logs will show whether the closed window was focused (a keypress) or not (a signal or CDP), and what ran in the seconds before. Its limit: it can't see short-lived `kill` calls that happen inside a script's own process.
4. The rule is in `docs/ASSUMPTIONS.md` (10:10 entry).
