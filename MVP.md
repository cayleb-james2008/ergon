# Ergon Minimum Viable Product (`MVP.md`)

**Baseline:** `cayleb-james2008/ergon` `v0.38.0` (`main` @ `28c3a7354`), audited **2026-11-26** via `cargo test` (`291` tests across `17` binaries), live CLI/HTTP checks, direct code inspection, uncut screen videos (`evidence/video/INDEX.md`, PR #10), and timing audit (`evidence/timing/2026-11-26/README.md`, PR #9).

---

## 1. Target Deployment Profile

A **~25-person regional field-services and installation company**: **project managers (PMs)**, **account executives (AEs)**, **office/admin staff**, and **field installers**.
- **Devices:** Windows/macOS laptops in the office and phones/tablets in the field (`/phone` responsive web view).
- **Operating model:** Non-technical staff run recurring admin, finance, contract, and reporting workflows with mandatory human approval before deletions or external sends; one IT/ops owner deploys, updates, backs up, and supports the server.

## 3. Deployment Basics Audit

1. **Install & update path (`Partial`):** `install.sh` installs cleanly on Linux (`--prefix`, `--data`, optional `systemd --user` unit; verified live + `ergon-installer-cli` video `PASS`). GitHub Release `v0.38.0` ships `4` platform binaries + `SHA256SUMS` (`.github/workflows/release.yml`), and `src/update.rs` (`17/17` tests) genuinely downloads over HTTPS, verifies SHA-256 + `--version`, and atomically swaps binaries (`notify`/`auto`/`off`). **Missing:** Windows/macOS installers & Windows service, Authenticode/Apple signing, and admin update flow on gated/shared hosts (`POST /api/update/{apply,restart}` returns `403`, `src/server.rs:2346`).
2. **Sign-in & permissions (`Missing`):** No user accounts, passwords, or SSO (`src/server.rs:62-66,2267-2270`). `ergon_session` cookies only pin a chosen profile in memory (`src/server.rs:77-81`); any caller can switch profiles via `POST /api/people/switch` (`HTTP 200` live, `src/server.rs:2595-2643`) to access another employee's workspace, CRM, invoices, or connector logs. `ERGON_GATE_TOKEN` is a single static proxy header, TLS is absent (raw HTTP), and `person.role` is prompt/label-only.
3. **Data backup & recovery (`Partial`):** Overwrites/deletes snapshot workspace files to `.history/` (`<=64` revs, `<=16 MiB/file`, `src/file_history.rs:18-19`) with 1-click restore (`POST /api/files/restore`); JSON stores write atomically and quarantine corrupt files to `.bak` (`src/lib.rs:634`). `src/audit_bundle.rs` exports read-only SHA-256 digests/handoff ZIPs, not full backups. **Missing:** Scheduled `ERGON_DATA_DIR` backup, offsite replication, and full restore CLI/UI.
4. **Error reporting (`Done`):** Thread-safe structured rotating JSONL logger (`src/logging.rs`) writes to `$ERGON_DATA_DIR/logs/ergon.log` (`5 MiB` default, `5` rotated backups `.1`..`.5`, `0600` POSIX) with multi-pass secret redaction (`Bearer`, `sk-*`, `xox*`, `api_key`, `password`, `token`, `secret`, `ERGON_GATE_TOKEN`, `ERGON_MODEL_API_KEY`, PEM keys, URL userinfo), replacing runtime `eprintln!` calls across `src/`. `[profile.release]` uses `panic = "unwind"` (`Cargo.toml:28`, also enabling `src/docs.rs:1087`'s PDF `catch_unwind` hook) with a global panic hook writing redacted JSON crash reports to `$ERGON_DATA_DIR/crashes/crash-*.json` and logging `ERROR` entries. `GET /api/diagnostics/bundle` and `ergon diagnostics [--data DIR] [--out BUNDLE.zip]` generate a redacted IT diagnostic ZIP (`system.json`, rotated logs, recent crash reports, `security_events.json`, secret-free `connectors.json`; verified `0` secret leaks in `tests/logging_crash_help.rs`).
5. **Offline / failure behavior (`Partial`):** Unconfigured `POST /api/chat` returns `HTTP 503` (`NO_KEY_ERROR`, `src/server.rs:6916`, verified live) while `12/12` deterministic skills (`/api/skills/test`) and deterministic pipelines run offline. Remote LLM calls retry `408/425/429/5xx`/transport drops (`4` attempts, `150s` budget, `src/lib.rs:1031-1049,1344-1375`). Interrupted DAG pipelines recover on boot (`src/pipelines.rs:1205`) and chat restores unsent drafts (`Chat.tsx:206`). **Gaps:** Ad-hoc chat `live_runs` are memory-only (crashes orphan runs), background scheduler skips zero-LLM routines without a model key (`src/server.rs:1029`), and `detect_local_gateways` (`src/lib.rs:342`) auto-probes localhost unless `ERGON_NO_AUTO_MODEL=1`.
6. **Non-technical employee help path (`Done`):** Fresh workspaces display a non-blocking 3-step plain-language orientation card (`frontend/src/shell/OnboardingCard.tsx`, persisted per workspace in `help_prefs.json` via `GET/POST /api/help/config`, dismissible and re-openable from Help). A persistent **Help & support** button (`#help-btn` in rail, `NoKeyBanner`, Settings, and `Cmd+K`) opens `HelpPanel.tsx` with plain-language troubleshooting guides, configurable **Contact your admin** details (Settings editor or `ERGON_ADMIN_CONTACT_*` env vars, with remote-gate `403` protection), and a prominent 1-click **Download IT Diagnostic Bundle** button. Verified end-to-end in `tests/logging_crash_help.rs` (`5/5 PASS`) and uncut video `ergon-logging-help` (`PASS`).

## 4. Explicitly Out of Scope (Does Not Block First Deploy)

- Native iOS/Android apps (authenticated HTTPS `/phone` suffices for field installers)
- Multi-region HA clustering or external SQL/S3 migration (one backed-up server fits 25 seats)
- Enterprise SAML/SCIM, SOC 2 Type II, or HIPAA packs (email/password or Google/M365 OIDC + basic RBAC suffices)
- Deep bi-directional ERP/dispatch sync (QuickBooks, ServiceTitan, Procore) beyond CSV, webhooks, and email
- Third-party plugin marketplace or cross-company skill sharing
- Per-laptop local GPU hosting, standalone `ergon-web.html` parity, or the out-of-repo `ergon-frontend` prototype
- Unattended outbound email/invoice sending (human approval stays mandatory for v1)
