## 3 · What the playtest found that the owner's list did not (ranked, player-facing)
1. **The guided path walks a new player into a wall.** "Next gate" and the Continue button take the FIRST unlocked, uncleared route in list order (`EncounterRoutes.luau:152, 181-191`) — after enc-3 that is **boss-1, which a level-1 deck cannot win until level 10**. The easier World 2 routes are never offered. Following the obvious button: 30/30 seeds stuck on boss-1 after 3 wins; first boss win took 129–169 duels (median 138, about 64 minutes of playback at 1x); in the first 15 minutes 9 of 10 seeds ended with 3 wins and 19–21 losses, each loss saying "+0 XP / Continue to the next unlocked route". The checker found the same code path independently (finding D10) as an omission in the freeze.
2. Card level, card XP, run level and run XP are shown nowhere; the Cards screen shows base stats (HP 58 / ATK 9) while the duel uses levelled stats (75 / 11). (Covered by Δ11.)
3. The XP numbers mislead: "+20 XP" is run XP, which does nothing; card XP (+25 per win, +5 per loss) is never reported; a loss says "+0 XP".
4. Skill points and rebirth are empty rewards: rebirth wipes levels and coins, run 2 costs the same 16 duels, and it yields 3 more do-nothing points. (Skill points: Δ2.)
5. Rolling is all-or-nothing luck: one Rare 4th card at level 1 beats 11 of 12 routes; four Rares, or any Mythic, win all 12 at level 1; duplicates do nothing; after level 10 rolling is pointless.
6. Dead or broken controls: auto-roll can never turn on (3 presses, flag stayed false); the guided "Your four are ready" jump never fires (client checks `pendingBattle == nil`, the server sends `false`); "Deck saved", shop-pack, rank-claim and rebirth-done messages are all overwritten by "Your saved run is ready"; saving an empty deck silently substitutes the first four owned cards alphabetically.
7. Phone: 31% card view; the battle control strip is 832 px wide in a 343–358 px bar, so Speed / Pause / Skip are off-screen; 3 of 7 nav tabs show.
8. First screen has two competing prompts (highlighted button "Take a free roll" vs text "NEXT MOVE: Build your first deck"); roll cooldown has no timer; HUD labels read "A:/B:" and show only the active cards' HP.
9. After the first minutes it is repetitive: 12 routes, single-card enemies, nearly deterministic damage.
Worked honestly: locked-route messages, double-claim safety, reconnect/resume of an unclaimed duel, exact odds and the pity counter.

**Playtester ratings (1–5, own judgement; the spec's pass rule is every rating ≥ 3 and Q4 not "no" — this pass would FAIL it, which the owner's own verdict supersedes):** first 15 minutes fun **2**; rolling still mattered at level 10 **1**; a duel felt like cards hitting cards **4** (73% of presentation time is strike animation; average duel 23.2 s at 1x, 11.6 s at 2x, 5.8 s at 4x); nothing dishonest or confusing **2**; phone and desktop both fine **2** (desktop ~4, phone ~2).

Milestones, cheapest honest route, median of 30 seeds (watch each duel at 1x / skip): first win 5 actions 0:33 / 0:12; first run level-up 17 actions ~2:55 / 0:36; first boss win 50 actions ~7:41 / 1:42; first rebirth 57 actions ~8:03 / 2:04. The freeze says "about 3–5 min" to the first boss win; that counts only the 15 farming wins (checker D12).
