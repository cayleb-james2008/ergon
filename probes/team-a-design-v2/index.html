Honest notes

This is a direction pass, not a finished front end. If the owner accepts the direction, the finished front end is built after that grade — inside the package work and behind its gates. These pages are comps: no plugin rows, no package files, no runtime claims.

Tokens live in tokens.json and are generated into tokens.css by build-tokens.mjs; no page hand-types a colour. Self-study runs with node check-comps.mjs (labels, self-containment, tokens-current, contrast floors, motion tells).

Taste reference: primeintellect.ai — taste only (restrained technical-editorial: near-black neutrals, 1px low-alpha hairlines, a fine scale with a mono companion, measured motion). No layout, marks or text is copied, and nothing was image-read into this session.
