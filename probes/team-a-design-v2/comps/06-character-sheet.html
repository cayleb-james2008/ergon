character system · light by design

A little neural net, not a blob.

The character is a node-and-connection mark. Customisation is deliberately light: structure (density), colour and name. It carries live state (idle / working / needs you) and nothing else — no creator, no accessories, no second library.

Live state — and the one-shot signal

idle — static mark, core in ink
working — one signal along the edges
needs you — core takes the warn token
A single directional signal per change — no pulse, no loop, no glow. Under reduced motion the state simply changes.

Why this reads as Ergon, not a mascot

  • Engineered, not cute: nodes and connections are drawn from a deterministic seed — the same name always gives the same network, so an employee's character is stable and theirs.
  • State is data: the core node and the word carry idle/working/needs-you; the mark never animates attention at you.
  • No creator: density, colour, name. That is the whole surface — matching the accepted light-customisation ruling.
  • It works small: the mark stays legible at 24 px in the desktop sidebar; at 34 px it shows the edges.
