Fences (held in every file)

  • No external assets: no CDN, no webfonts (system stack from the tokens), no images; all visuals are CSS or inline SVG.
  • Tokens only: every colour, type size, space, radius and target comes from tokens.css, generated from the pack's design/tokens.json; no hand-typed hex in any comp.
  • Nothing copied from the Glitch Cat Club source repository (that repo has no licence file; method only).
  • No code: the comps are static HTML/CSS with no scripts; nothing is wired to a plugin, package or fleet surface.
  • $0: no purchases, no sends, no credentials.
