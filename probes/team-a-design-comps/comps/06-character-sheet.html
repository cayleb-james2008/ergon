Character sheet

The agent's character: bubbly defaults, three shapes and colours to start from, and the live-state language on a small face. Customisation is shape + colour + name only — there is no character creator.

Defaults are bubbly, buildable-icon characters; one pinned library supplies the shapes (identification is a research item; the fallback shape is a DiceBear-class bubbly persona style).

Live state on the character — flat disc, no glow

Working
ok token · disc
Idle

State reads at a glance next to the face; the word is available (tap/tooltip) so colour is never the only signal. No pulse, no glow, no effects on the character — the transition between states is the animation (motion spec §3).

Customisation surface — exactly three things

Shape

Pick one of the default shapes.

Colour

Pick one token colour for the character.

Name
Nothing else

No body editor, no accessories, no creator. Anything beyond shape, colour and name is scope creep against the owner ruling.
